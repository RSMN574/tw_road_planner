# 台灣通 UI v2 設計規格（v1.12）

參考主流導航 App 的資訊架構（地圖為背景、藍白主色、半透明卡片、底部可拖拽面板、導航中轉向卡），**保持自己的品牌**：
- 不使用任何第三方導航 App 的商標、Logo、圖標、截圖或字體。
- 圖標全部自繪（`js/ui-icons.js`，簡單幾何 SVG）。
- 字體用系統字（`system-ui`、`PingFang TC`、`Microsoft JhengHei`、`Noto Sans TC`）。
- 地圖為 OpenStreetMap（ODbL，畫面保留「© OpenStreetMap contributors」）。
- 大眾運輸與道路事件資料來自 TDX（交通部，需依其授權條款標示來源）。

> 品牌暫定（待確認）：名稱「台灣通」、主色 #1A73E8、自繪標誌。都集中在 `css/app.css` 的 token 區，一處修改即可。

---

## 1. 現況問題與改進方向

| # | 問題 | 改進 |
|---|---|---|
| 1 | 桌機是 340px 固定左欄，手機是佔 62% 高度的抽屜；地圖不是主角 | 各尺寸一律以**全螢幕地圖**為背景，控制項浮在上面 |
| 2 | 面板是工程工具式長表單：資料載入、演算法、權重都和「去哪裡」擺在一起 | 第一層只留「去哪裡、怎麼去、走哪條」；其餘收進選單（進階） |
| 3 | 搜尋在面板裡，看不到地圖就無法搜尋 | 頂部常駐搜尋列（目的地）＋語音輸入 |
| 4 | 路線結果是小字清單，看不出推薦方案與差異 | 橫向的路線方案卡片：時間、距離、到達時刻、紅綠燈、收費、施工事件，標示「推薦」 |
| 5 | 深色模式把地圖顏色反相，道路與路線顏色失真 | 用設計 token 定義兩套色彩，地圖也有對應的深色配色 |
| 6 | 導航轉向用 emoji，各平台長相不同；重要轉向沒有放大 | 自繪轉向圖示；接近轉彎時卡片放大、字更大 |
| 7 | 導航底部有 4 顆同大小的按鈕，容易誤觸「結束」 | 剩餘資訊為主；「結束」獨立在一側，次要功能收進「更多」 |
| 8 | 地圖控制列（8 顆按鈕）擠在右上，手機上會擋路線 | 分成右上（圖層、路況、2D／3D、指北）與右下（定位、縮放）兩組 |
| 9 | 沒有空狀態、載入中、錯誤狀態的設計 | 三種狀態都有固定樣式，失敗時附「重試」 |

**資料限制（不偽造）**：

| 需求 | 現有資料 | 做法 |
|---|---|---|
| 紅／黃／綠路況、擁堵里程 | 沒有即時路況（TDX 路況 API 未接） | 路況條顯示「無即時路況資料」的灰色條；改用 **TDX 道路事件**（施工、事故、管制）標在路況條與地圖上 |
| 車道提示 | OSM `turn:lanes` 尚未擷取 | 這一版不顯示車道區；元件先預留 |
| 紅綠燈數量 | OSM 號誌 | 有，伺服器新增 `signals` 欄位 |
| 收費 | 只能判斷是否行經國道 | 顯示「含國道 N km（收費，費率未計）」 |
| POI 與評分 | 沒有 | 下一批（需先決定資料來源） |

## 2. 資訊架構與流程

```
主介面（地圖＋頂部搜尋＋浮動按鈕＋底部面板：收合）
 ├─ 搜尋目的地（頂部）──選結果──▶ 路線規劃
 ├─ 常用地址（家、公司、最近）──點選──▶ 路線規劃
 ├─ 點地圖選點 ──▶ 路線規劃
 ├─ 選單 ▶ 交通方式預設、地圖圖層、深色模式、省電樣式、資料與進階設定（原面板內容）
 │
路線規劃（底部面板：半展開）
 ├─ 起點（預設目前位置）／終點、交通方式切換
 ├─ 路線方案卡片（橫向，可左右滑）── 點選 ▶ 地圖高亮該路線
 ├─ [開始導航]（主按鈕）
 └─ 詳細：逐步指示、路線分析（上拉全展開）
 │
導航中（全螢幕地圖，只剩轉向卡＋剩餘資訊卡＋回到定位）
 ├─ 偏航 ▶ 重新規劃提示 ──▶ 導航中
 ├─ 抵達 ▶ 抵達卡 ──▶ 主介面
 └─ 結束 ▶ 主介面
```

底部面板三段高度：**收合**（約 96px，只露出把手與摘要）、**半展開**（約 48% 高）、**全展開**（約 92% 高）。

## 3. 設計 token

### 3.1 顏色

| token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--c-primary` | #1A73E8 | #8AB4F8 | 主按鈕、選中、路線 |
| `--c-primary-strong` | #1557B0 | #AECBFA | 主按鈕按下 |
| `--c-on-primary` | #FFFFFF | #0B1A33 | 主色上的文字 |
| `--c-bg` | #F1F3F4 | #0E1116 | 頁面底色 |
| `--c-surface` | rgba(255,255,255,.94) | rgba(28,31,38,.94) | 卡片（半透明） |
| `--c-surface-solid` | #FFFFFF | #1C1F26 | 降級時的卡片 |
| `--c-surface-2` | #F1F3F4 | #2A2E37 | 次要區塊、輸入框 |
| `--c-text` | #202124 | #E8EAED | 主要文字（對比 ≥ 12:1） |
| `--c-text-2` | #5F6368 | #BDC1C6 | 次要文字（≥ 4.5:1） |
| `--c-text-3` | #80868B | #9AA0A6 | 提示文字（≥ 3:1，只用在 ≥ 14px） |
| `--c-border` | #DADCE0 | #3C4043 | 分隔線 |
| `--c-good` | #188038 | #81C995 | 暢通 |
| `--c-slow` | #B06000 | #FDD663 | 緩行（淺色用深橘，才有足夠對比） |
| `--c-jam` | #C5221F | #F28B82 | 擁堵、錯誤、結束導航 |
| `--c-nav` | #1A73E8 | #174EA6 | 導航轉向卡底色 |
| `--c-map-bg` | #EEF0EC | #1B1F27 | 地圖底色 |

路況三色在色塊旁一律加文字或圖示（「施工」「擁堵」），不只用顏色區分（色盲友善）。

### 3.2 字級（rem，根字級 16px；車機 ×1.25）
`--fs-xs` 12 ｜ `--fs-sm` 14 ｜ `--fs-md` 16 ｜ `--fs-lg` 20 ｜ `--fs-xl` 24 ｜ `--fs-2xl` 32 ｜ `--fs-nav` 40（轉向距離）。字重：一般 400、標題 600、數字 700，數字用等寬數字（`tabular-nums`）。

### 3.3 間距、圓角、陰影
- 間距：4／8／12／16／24／32（`--sp-1`～`--sp-6`）。
- 圓角：`--r-sm` 12（輸入框、晶片）、`--r-md` 16（卡片）、`--r-lg` 20（底部面板、轉向卡）、`--r-pill` 999。
- 陰影：`--sh-1`（浮動按鈕：0 1px 3px／0 1px 2px）、`--sh-2`（卡片：0 4px 12px）、`--sh-3`（底部面板：0 -6px 24px）。
- 觸控區：最小 44×44；車機最小 56×56。
- 毛玻璃：`backdrop-filter: blur(12px) saturate(1.2)`，只用在頂部搜尋列、浮動按鈕、底部面板三處；不支援、`prefers-reduced-transparency`、或選單開「省電樣式」時，改用不透明的 `--c-surface-solid`。

## 4. 元件清單

| 元件 | 說明 | 狀態 |
|---|---|---|
| 搜尋欄 `.ds-search` | 選單鈕＋輸入框＋語音鈕；結果下拉在搜尋欄下方 | 一般／聚焦／有結果／無結果 |
| 語音按鈕 `.ds-mic` | Web Speech API（zh-TW）；瀏覽器不支援時隱藏 | 待命／收音中（脈動）／錯誤 |
| 浮動地圖按鈕 `.ds-fab` | 44×44 圓角 14、半透明；分右上、右下兩組 | 一般／按下／開啟（主色） |
| 底部可拖拽面板 `.ds-sheet` | 把手＋三段吸附；拖曳或點把手切換；鍵盤可操作 | 收合／半展開／全展開 |
| 路線方案卡片 `.ds-route` | 時間（大字）、距離、到達時刻、標籤、紅綠燈、收費、事件、路況條 | 一般／選中／推薦／載入骨架 |
| 路況條 `.ds-traffic` | 依路線長度切段上色；沒有路況資料顯示灰條和文字 | 有資料／無資料 |
| 路況標籤 `.ds-chip` | 暢通／緩行／擁堵／施工／事故 | — |
| 轉向提示卡 `.ds-turn` | 圖示＋距離＋路名＋接著 | 一般／即將轉彎（放大）／偏航（警示） |
| 剩餘資訊卡 `.ds-remain` | 剩餘時間、距離、到達時刻 | 一般／定位異常 |
| 狀態卡 `.ds-state` | 空、載入、錯誤（含重試） | — |

## 6. 程式

- `css/app.css`：v1.12 區段（token、版面、元件、深色、車機、降級）。
- `js/ui-shell.js`：搜尋列、浮動按鈕分組、底部面板拖拽、路線卡、狀態、常用地址、語音、主題、日出日落。
- `js/ui-icons.js`：自繪圖示。
- 修改：`js/osm.js`（深色地圖配色）、`js/nav-ui.js`（轉向卡與剩餘卡）、`js/pwa.js`（主題三態）、`server/osm/router.mjs`（`signals`）。

## 7. 驗收清單

**視覺**
- [ ] 地圖全螢幕；主色只用在主按鈕、選中與路線。
- [ ] 卡片圓角 12～20；文字分成四個層級。
- [ ] 沒有任何第三方 Logo、專有圖標、截圖或字體。

**互動**
- [ ] 底部面板可拖到三段高度並吸附；點把手可切換；鍵盤（Enter、↑↓）可操作。
- [ ] 路線卡可點選，選中有明顯外框，地圖同步高亮。
- [ ] 搜尋列輸入後有下拉結果；語音可以輸入（支援的瀏覽器）。
- [ ] 導航中距離轉彎 < 200 m（步行 < 60 m）時轉向卡放大；「結束」與其他按鈕分開。

**響應式**
- [ ] 手機直向 375×812、平板 768×1024、桌機 1440×900、車機 1280×720 橫向都不遮擋路線與轉向資訊。

**夜間模式**
- [ ] 預設跟隨系統；選單可切換「自動／淺色／深色」；地圖、卡片、建築、路線都有深色樣式（不是反相）。

**無障礙**
- [ ] 主要文字對比 ≥ 7:1、次要 ≥ 4.5:1；觸控區 ≥ 44（車機 56）。
- [ ] 圖示按鈕都有 `aria-label`；面板有 `role=dialog`／`aria-expanded`；支援 `prefers-reduced-motion`。
- [ ] 路況不只靠顏色（有文字標籤）；語音提示保留。

**效能**
- [ ] 毛玻璃只用在 3 處；`prefers-reduced-transparency` 或「省電樣式」自動降級。
- [ ] 拖曳面板只改 `transform`（不觸發地圖重繪）；地圖互動維持 60 fps（桌機）。

**版權合規**
- [ ] 地圖署名（OSM）、資料來源（TDX）可見；圖示自繪；字體為系統字。
