# 店家地點（POI）搜尋：規劃

狀態：**第一階段已實作（v1.13.0）**；第二階段（途經點）、第三階段尚未開始。數字都是 2026-11-24 對本機 `taiwan-20261117.osm.pbf` 實際計算的結果。

實作與規劃不同的地方：
- 資料檔是 `osm-poi.json.gz`（gzip JSON，約 5 MB），不是自訂二進位；載入＋建索引約 2 秒，伺服器預熱時就載入。
- 單一地點 API 是 `GET /api/v1/poi/detail?id=n123`（不是 `/poi/{id}`；現有路由表只比對固定路徑）。
- 空間格網約 1 km 一格（不是 500 m）。
- 「店名 地標」（例如「麥當勞 台北車站」）：以地標為中心，只留 5 km 內；「附近還有 N 家」只算 5 km 內。
- 回應沒有 `groups` 欄位；連鎖店合併以每筆的 `moreSameName` 表示。

## 1. 目標

在頂部搜尋列輸入店名、品牌或類別（例如「全家」「麥當勞」「加油站」「台大醫院」），就能：
- 看到附近、依距離與相關度排序的店家清單。
- 在地圖上看到對應標記，清單與標記互相連動。
- 開啟詳細卡：名稱、類別、距離、地址、營業時間（營業中／已打烊）、電話、網站。
- 一鍵「設為目的地」或「設為起點」，「加入途經點」放在第二階段。

## 2. 資料來源

### 2.1 建議：OpenStreetMap（已在本機，授權為 ODbL）
台灣 OSM 中有 `shop`、`amenity`、`tourism`、`leisure`、`office`、`craft`、`healthcare` 標籤的地點：

| 項目 | 數量 |
|---|---:|
| 全部（點 190,408＋面 109,271） | 299,679 |
| 有名稱 | 197,074 |
| 有營業時間 `opening_hours` | 40,919（13.7%） |
| 有電話 | 34,560 |
| 有網站 | 17,608 |
| 有門牌（街道＋號） | 約 73,000～75,000 |
| 有品牌 `brand` | 46,133 |
| 有英文名 | 50,231 |

最多的類別：餐廳 38,212、汽機車停車格 21,921、停車場 18,207、旅遊資訊 17,144、宗教場所 14,590、便利商店 13,425、運動場 9,924、YouBike 等租借站 8,515、公園 8,118、咖啡廳 6,492。

**要先過濾**：停車格、長椅、垃圾桶、飲水機、遮雨棚、置物櫃等不是「店家」，不進搜尋，或只能用類別找。估計過濾後約 15～18 萬個有名稱的地點。

### 2.2 OSM 的限制（不會假裝有）
- **沒有評分與評論**：介面不顯示評分。
- 營業時間只有約 14% 有資料；沒有的顯示「營業時間未提供」。
- 覆蓋率依地區與志工貢獻而定：都市較完整，鄉鎮可能缺；新開或已關的店不會即時反映（要定期重建）。
- 不是每家都有門牌；沒有的顯示所在路名（由最近的道路推出），並標示「附近道路」。

### 2.3 其他來源評估（目前不建議）
| 來源 | 問題 |
|---|---|
| Google Places API | 付費；條款要求 Places 結果必須顯示在 Google 地圖上，不能疊在自己的 OSM 地圖上 |
| Foursquare／HERE 等商用 POI | 付費、需簽約，資料不能長期快取 |
| 政府開放資料（商業登記、特定行業名冊） | 多半只有地址沒有座標，要另外做地址定位；類別不完整 |

以上都可以之後當成第二資料層加入，第一階段只用 OSM。

## 3. 架構（沿用現有的建圖、伺服器、圖磚模式）

```
taiwan-*.osm.pbf ──tools/osm/osm-poi.mjs──▶ data/osm/graph/<日期>/osm-poi.twpoi（二進位：座標、類別、字串表、索引）
                                              │
server/osm/poi.mjs（載入、搜尋、附近、營業判斷）◀─┘   ← 在 OSM 背景執行緒裡（和路網同一處）
        │  GET /api/v1/poi/search · /poi/nearby · /poi/{id}
js/poi.js（搜尋結果、類別快捷、地圖標記、詳細卡）◀── 頂部搜尋列（ui-search.js／ui-shell.js）
```

### 3.1 擷取 `tools/osm/osm-poi.mjs`（約 30～60 秒）
- 和建築擷取一樣讀 PBF 三趟（relation→way→node）；面狀地點（way）取中心點，並把邊界盒存下來供大型地點（醫院、校園）判斷範圍。
- 每筆存：OSM id 與型態、名稱、英文名、品牌、類別碼（約 60 類，對應中文名稱）、座標、地址（`addr:*` 組合）、營業時間原字串、電話、網站、樓層。
- 類別對照表 `server/osm/poi-categories.mjs`：OSM 標籤 → 中文類別（例如 `amenity=fuel`→加油站、`shop=convenience`→便利商店、`amenity=pharmacy`／`healthcare=pharmacy`→藥局）、對應圖示、是否算店家。

### 3.2 索引與排序 `server/osm/poi.mjs`
- **中文**：名稱與品牌拆成單字＋相鄰兩字（bigram），建倒排索引。可以搜到「台大醫院」「大醫院」「醫院」；「台／臺」、全形／半形、大小寫都先正規化。
- **英數**：拆成詞並支援前綴（「7-11」「mcd」「starb」）。
- **同義詞**：小表，例如 7-11／小七／統一超商、全家／FamilyMart、麥當勞／McDonald's、星巴克／Starbucks、全聯、加油站／中油／台塑石化。
- **類別詞**：「加油站」「便利商店」「咖啡」「藥局」「ATM」「停車場」「廁所」等，直接變成類別查詢，不比對名稱。
- **空間格網**：約 500 m 一格，給「附近」查詢與地圖範圍查詢用。
- **排序分數**＝文字相符程度（完全相同 > 開頭相同 > 包含）×（品牌、有名稱加分）× 距離衰減（以地圖中心或 GPS 位置為準，對數衰減，5 km 外大幅降低）。同名連鎖店只回最近的幾家，再加一列「附近還有 N 家」。
- 記憶體估計：約 15 萬筆、字串加索引約 30～50 MB（每個背景執行緒一份）；單次查詢目標 < 20 ms。

### 3.3 營業時間
沿用 `server/osm/conditional.mjs` 的 opening_hours 判斷（轉向限制已經在用）：
- 可以判斷 → 顯示「營業中」「已打烊」「即將打烊（30 分內）」，並列出今天的時段。
- 判斷不了（國定假日規則、`sunrise` 等）→ 顯示原文，不猜。
- 沒有資料 → 「營業時間未提供」。

## 4. API

| 方法 | 路徑 | 參數 | 回傳 |
|---|---|---|---|
| GET | `/api/v1/poi/search` | `q`、`near=緯度,經度`、`bbox`、`category`、`openNow=1`、`limit`（≤ 30） | `results[]`：id、名稱、類別、距離、座標、地址、營業狀態；`groups`（連鎖店合併）；`note` |
| GET | `/api/v1/poi/nearby` | `lat`、`lon`、`category`、`radius`（≤ 5 km）、`limit` | 同上，依距離排序 |
| GET | `/api/v1/poi/{id}` | — | 完整欄位：電話、網站、營業時間原文與判斷、樓層、OSM 連結 |
| GET | `/api/v1/poi/categories` | — | 類別清單、圖示名稱、全台數量 |

快取、限流、錯誤格式和現有 OSM API 相同；`meta.poiVersion` 跟著資料版本變。

## 5. 介面（接在 UI v2 上）

1. **頂部搜尋下拉**：分兩區，「地點」（店家，最多 8 筆：圖示、名稱、類別．距離、營業狀態）和「道路」（現有的路名搜尋）；「查看全部 N 筆」打開底部面板清單。
2. **類別快捷**：搜尋框聚焦時，下方出現一排類別鈕：加油站、便利商店、餐廳、咖啡、停車場、ATM、醫院／診所、藥局。點了就做「附近」查詢。
3. **結果清單（底部面板）**：每列有名稱、類別、距離、地址、營業狀態，右側「導航」鈕；可篩選「營業中」。
4. **地圖標記**：結果以編號圓點顯示；點標記會捲動並高亮清單那一列，點清單也會把地圖移到該標記；縮小時標記會合併成數字群組。
5. **詳細卡**：名稱、類別、營業狀態與今日時段、地址、電話（點了直接撥打）、網站，按鈕「設為目的地」「設為起點」；底部署名「資料：© OpenStreetMap contributors」。
6. **空、載入、錯誤狀態**：沿用 UI v2 的狀態卡；「找不到」時提示改用類別或路名。

## 6. 途經點（第二階段）
路由目前只有起點→終點。途經點要：
- 伺服器分段規劃 A→V→B 再接起來，步驟中標示「抵達途經點」。
- 導航引擎把途經點當成一個步驟。
- 介面讓起訖之間可以新增、刪除、拖曳排序。

所以和搜尋分開做。

## 7. 測試
| 測試 | 類型 |
|---|---|
| 正規化、bigram、同義詞、類別詞、排序 | 單元 |
| 營業時間判斷（含跨午夜、假日規則無法判斷） | 單元 |
| 擷取→檔案→載入→API（用小型測試 PBF，含點、面、無名、要排除的類別） | 整合（模擬資料） |
| 全台真實資料抽查：「全家」在台北車站附近 500 m 內、「台大醫院」第一名正確、「加油站」依距離、英文「Starbucks」 | 真實資料 |
| 查詢時間、記憶體 | 真實資料量測 |
| 搜尋→選取→設為目的地→規劃→導航（瀏覽器） | 端對端 |
